# Contributing to Poswal Orbit

Thank you for your interest in contributing to **Poswal Orbit**. We welcome bug reports, design improvements, and pull requests.

## How to Contribute

1. **Check Existing Issues**: Search the GitHub Issues tab before opening a new issue or PR.
2. **Open an Issue**: For major changes or new features, open a discussion issue first to align on architecture and design.
3. **Branching**:
   - Create a feature branch from `main`: `git checkout -b feat/your-feature-name` or `fix/your-fix-name`.
4. **Code Standards**:
   - Follow Flutter and Dart official style conventions.
   - Run `flutter analyze` and ensure zero warnings or errors.
   - Run `flutter test` and add tests for any new domain logic or widgets.
   - Maintain the Liquid Glass design guidelines and design tokens in `lib/core/theme/poswal_tokens.dart`.
5. **Submit a Pull Request**:
   - Fill out the PR template completely.
   - Reference the related issue number.

## Code of Conduct

All contributors and participants agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
