# Security Policy

## Supported Versions

Poswal Orbit receives active security updates on the latest main branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Poswal Orbit, please report it responsibly:

1. Do **NOT** open a public issue.
2. Please use GitHub's private vulnerability reporting feature on this repository under **Security > Report a vulnerability**.
3. Include detailed steps to reproduce the issue and the potential impact.
4. Maintainers will review and respond within 48 hours.
